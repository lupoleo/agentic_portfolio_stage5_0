# S5.0-2 (block 1) — Account sync, versioned state and TEMPORARY simulation

Status: IMPLEMENTED 2026-11-06. Architecture: `STAGE_5_0_ARCHITECTURE.md` §4.3, §5A, §5C.

## What was built

| Module | Role |
| --- | --- |
| `app/broker/ibkr_client.py` | `ReadOnlyIbkrClient`: read-only allowlist enforced before the transport; `RecordedTransport` for replay |
| `app/broker/models.py` | `AccountReading`, `StateVersion`, `StateChange`, `SyncResult`, `PortfolioMode`, `StateOrigin`, `AccountProfile` |
| `app/broker/normalize.py` | IBKR connector responses → canonical records |
| `app/broker/fingerprint.py` | Structural, account and profile fingerprints (prices excluded from structural) |
| `app/broker/state_diff.py` | Change classification: opened/closed/quantity, cash, account risk, open orders, profile, valuation drift |
| `app/broker/sync_store.py` | Append-only SQLite (`state_version`, `sync_run`; UPDATE/DELETE blocked by triggers) |
| `app/broker/account_sync.py` | `AccountSyncService.sync()`: new version only on material change, `NO_CHANGE` runs recorded |
| `app/broker/sources.py` | `LiveIbkrAccountSource`; TEMPORARY `SimulatedFinecoUsdSource` + `SimulationFixture` |
| `app/broker/cio_adapter.py` | Bridge to the frozen CIO contracts (`AccountState`, snapshot reference) |
| `app/cio/models.py` | Additive: `DataSource.IBKR`, `DataSource.IBKR_SIMULATED` |
| `tools/stage5_account_sync.py` | CLI replaying recorded IBKR readings in live or simulated mode |

## Default tolerances

Cash 0.01 per currency; account metrics 5% relative; leverage 0.05; valuation
drift 2% of net liquidation. They are policy values in `DiffTolerances`.

## Evidence

* Offline regression: 1816 baseline tests + 38 broker tests + 2 recorded
  acceptance tests, all green (`python -m pytest -q -p no:cacheprovider`).
* Real recordings (read-only, git-ignored): the 2026-11-04 → 2026-11-06 replay
  detects the sale of DHR (`POSITION_CLOSED 6442`), the USD cash change and
  the margin release, creating version 2 with a parent link to version 1.
* Simulation: 12 Fineco USD stocks, NLV = real IBKR NLV + simulated value at
  the IBKR USD rate (≈ EUR 110.8k on 2026-11-06); every record marked
  `SIMULATED_TEMPORARY`.
* Broker calls in every run: read tools only; orders submitted, portfolio
  mutations and automatic executions all 0.
